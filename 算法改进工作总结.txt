多无人机吊运系统穿框规划算法改进工作总结

本文档用于向其他 AI 智能体说明：在原 MARTS-Planner 方法基础上已经完成、保留或曾经尝试过的算法改进。地图构建、RViz 配色、CSV 日志和程序崩溃修复等工程工作不计入算法创新。

一、原方法及主要问题

原方法采用“前端 A* 离散路径搜索 + 后端 MINCO 连续轨迹优化”的框架。前端节点主要表示负载位置 (x,y,z)，在候选位置遍历缆绳倾角，只要存在一个可行倾角就认为该位置可通过；后端再根据抽取的负载航点联合优化负载轨迹、缆绳角度和无人机轨迹。

在连续矩形框环境中发现两个主要问题：

1. 前端只保存负载位置，没有保存系统以什么构型到达该位置，无法规划连续的构型变化。
2. 后端只接收稀疏负载航点，优化轨迹和缆绳倾角可能明显偏离前端结果，造成负载、缆绳或无人机碰撞。

当前改进框架为：

体素地图 -> 位置-构型扩展 A* -> {负载位置、最优倾角、安全裕度} -> 安全约束下的位置-构型联合引导路径平滑 -> 后端构型跟踪和自适应全系统安全走廊生成 -> MINCO 连续轨迹优化。

二、位置-构型联合搜索的扩展 A*

1. 搜索状态扩展

原搜索状态为：

s_i = (x_i,y_i,z_i)

现扩展为：

s_i = (x_i,y_i,z_i,k_i)

其中 k_i 是缆绳倾角 theta_i 的离散编号。因此，同一负载位置下的不同吊运构型会作为不同节点保存，各自具有独立的累计代价、父节点和安全裕度。

当前倾角参数为：

theta_min = 8.4 deg
theta_max = 60 deg
N_theta = 10

每个负载位置最多对应 11 个倾角状态，缆绳长度为 1.5 m。

2. 构型连续扩展

对每个三维空间邻居，同时扩展倾角状态：

k_(i+1) in [k_i-delta_k_max, k_i+delta_k_max]

当前 delta_k_max = 1，即相邻节点最多变化一个角度档位，避免构型突然收缩或展开。

A* 内部起点构型按初始倾角 39.36 deg 初始化；终点不固定倾角，而是在所有能够到达目标位置的构型中选择总代价最低者。

3. 相邻节点连续可行性检查

原方法主要检查离散节点处的包络，无法保证两个安全节点之间的运动过程安全。当前对每条候选边同时插值负载位置和倾角：

p(lambda) = (1-lambda)p_i + lambda*p_(i+1)
theta(lambda) = (1-lambda)theta_i + lambda*theta_(i+1)

其中位置采样步长不大于 0.1 m，倾角采样步长不大于 3 deg。任意插值状态发生碰撞，该边都会被拒绝。

4. 全系统实体尺寸检查

前端包络按高度分层检查，并对不同层使用不同实体半径：

负载半径：r_L = 0.05 m
缆绳半径：r_C = 0.02 m
无人机半径：r_Q = 0.125 m
额外硬安全裕度：r_s = 0.10 m

底层考虑负载，中间层考虑缆绳，顶层考虑无人机。例如无人机层必须满足障碍物距离不小于 0.225 m。因此前端可行性不再只表示包络采样点没有落入障碍物，而是考虑了系统的物理尺寸。

三、环境-构型联合评价函数

改进后的 A* 评价函数为：

f(s) = w_a*g(s) + w_b*h(s)

其中 h(s) 是负载位置到目标位置的欧氏距离，当前 w_a = 1，w_b = 1。累计代价为：

g_(i+1) = g_i + J_d + w_c*J_c + w_s*J_s + w_n*J_n

当前矩形通道实验采用：

w_c = 2
w_s = 3
w_n = 1

1. 路径距离代价 J_d

J_d = ||p_(i+1)-p_i||_2

用于限制负载路径长度。

2. 安全裕度代价 J_c

设候选边上完整系统包络的最小有效安全裕度为 c_i，软安全阈值为 c_s = 0.6 m。当 c_i 小于 c_s 时：

J_c = ((c_s-c_i)/c_s)^2

当 c_i 大于等于 c_s 时，J_c = 0。

其中 0.10 m 是必须满足的硬安全裕度，0.60 m 是产生软惩罚的期望安全距离，两者作用不同。

3. 构型平滑代价 J_s

J_s = ((k_(i+1)-k_i)/N_theta)^2

用于抑制相邻节点的倾角变化。该项描述的是路径域构型平滑性，不等同于时间域缆绳角速度约束。

4. 标称构型代价 J_n

J_n = (k_i/N_theta)^2

按照当前编号方式，k = 0 对应最大倾角，因此 J_n 倾向于使系统在空旷区域保持较展开的标称构型；进入狭窄区域时，安全代价可以推动系统主动收缩。

前端最终输出的位置-构型路径同时包含负载位置、最优倾角和安全裕度。

四、后端构型跟踪

新增了前端构型路径数据接口，每个节点向后端发送：

1. 负载位置 p_i。
2. A* 最优倾角 theta_i。
3. 全系统安全裕度 c_i。
4. 是否被抽取为普通负载航点。

后端在每个 MINCO 积分采样点，将当前负载位置 p(t) 投影到最近的 A* 路径线段，并在线段两端的倾角之间插值：

theta_ref(t) = (1-alpha)theta_i + alpha*theta_(i+1)

然后对每根缆绳加入构型跟踪代价：

J_track = w_track * sum integral((theta_k(t)-theta_ref(t))^2)dt

当前跟踪权重 w_track = 5000。该项已加入 MINCO 目标函数及其梯度，并用于初始化部分构型变量。

目前只跟踪缆绳倾角 theta，没有跟踪方位角 psi。它是软约束，因此能够减小但不能彻底消除前后端构型差异。当动力学、时间、能量、平滑性和避障目标发生冲突时，后端仍可能偏离前端参考构型。

A* 的 getPath() 不包含真正的起点节点，因此前端单独保存 A* 实际选中的起点倾角，并用它构造起点参考点，确保走廊起始状态和后端收到的首个参考倾角都与 A* 内部起点构型一致。

五、自适应全系统安全走廊

走廊约束变量是负载中心位置，但生成过程中考虑完整吊运系统包络，因此准确含义是“考虑全系统包络的负载中心安全走廊”。

0. 安全约束下的走廊引导路径平滑

A* 原始位置-构型序列只作为拓扑可行的离散参考，不再直接作为走廊中心线。在走廊生成前，对负载位置和缆绳倾角同时进行局部平滑。每个候选更新均限制相对原始 A* 节点的最大偏移，并使用与扩展 A* 相同的负载、缆绳和无人机完整包络模型，检查候选状态以及前后两段位置-倾角连续过渡。若不安全，则采用逐级减半的回溯步长；仍不可行时保留原节点。该平滑仅服务于走廊生成，不改变传递给后端的 A* 构型参考。

当前矩形通道实验采用 8 轮平滑，位置平滑增益 0.45、倾角平滑增益 0.35，最大位置偏移 0.6 m。最近测试中，引导路径长度由 35.038 m 降至 32.750 m，最大离散转折角由 114.095 deg 降至 53.008 deg，最终所有平滑路径边均通过完整系统连续碰撞检查。

1. 环境复杂度

对候选路径段计算最小障碍距离 d_min 和局部占据率 rho_occ：

C = w_d/(d_min+r_grid) + w_rho*rho_occ

当前 w_d = 0.8，w_rho = 3.0。障碍物越近、局部障碍物越密集，环境复杂度越大。

2. 自适应分段

L_seg = clip(L_max/(1+C), L_min, L_max)

当前 L_min = 0.8 m，L_max = 2.4 m。障碍物密集区域分段更短，空旷区域分段更长。

3. 自适应局部范围

R = clip(gamma*d_min/(1+w_rho*rho_occ), R_min, R_max)

当前 gamma = 1.5，R_min = 0.6 m，R_max = 2.0 m。

4. 构型相关包络补偿

对多面体平面法向量 n，计算该路径段所有前端倾角下完整系统包络的最大支撑距离：

R_seg(n) = max over theta in Theta_seg and q in E(theta) of n^T*q

生成障碍物分离平面时，在该支撑距离上继续增加 0.10 m 安全裕度，由此得到凸多面体：

C_j = {p in R^3 | A_j*p <= b_j}

对于轴对齐矩形框，会在径向法向量和正负 X、Y、Z 方向中选择更合适的障碍物分离方向。

5. 狭窄位置保守补充

如果普通凸多面体无法覆盖某个狭窄节点，则先逐步缩短路径段。若缩短后仍无法生成普通多面体，则检查当前节点到下一节点的整条位置-构型过渡边，得到沿边的最小全系统剩余安全距离 c_edge。在该安全距离内构造沿路径边方向的桥接棱柱，其当前安全系数为 0.6，横向半宽为：

w_bridge = 0.6*c_edge/sqrt(3)

桥接棱柱覆盖整条相邻边，并在端点方向保留少量重叠，用于消除框前、框后和路径升降转折处的单点断裂。它的尺寸由负载、缆绳和无人机完整包络的连续碰撞检查结果确定，并非只使用负载中心 EDT 距离。只有当相邻边也无法生成桥接棱柱时，才使用剩余安全球内的小立方体作为最终兜底。

为保证走廊序列真正连通，每生成一个新多面体，都会与前一个多面体联合求解最大内接球半径，以此作为有效重叠尺度。当重叠半径小于当前阈值 0.01 m 时，即使两个普通多面体都生成成功，也会沿两者之间已通过连续安全检查的 A* 边自动插入桥接棱柱。

目前已经完成走廊生成、全系统包络补偿、连通性修复和 RViz 可视化。最近测试生成 55 个凸多面体，包含原有 4 个狭窄位置桥接棱柱和新插入的 10 个连通性桥接棱柱，单点兜底立方体为 0，平滑引导路径未覆盖点为 0。55 个多面体的 54 对相邻交集全部有效，最小重叠内接球半径为 0.0606 m，未修复断口为 0。

需要特别说明：走廊尚未传入 MINCO 作为后端约束，因此当前只能称为安全走廊生成方法，不能宣称已经实现后端硬走廊约束。

六、曾尝试但当前未启用的算法方案

1. 根据低安全裕度区域设置硬负载航点：当前关闭。
2. 根据环境复杂度动态抽取后端航点：已回退，目前每 7 个 A* 节点固定抽取一个。
3. 缆绳倾角角速度、角加速度代价和软限制：代码保留，但当前权重均为 0。
4. 缆绳运动学违规后直接拒绝轨迹：当前关闭。
5. 释放终点方位角 psi：实验后回退，当前关闭。
6. 多轮信赖域小步优化：实验效果不理想，已回退。
7. 将负载安全走廊作为后端软惩罚：曾尝试但效果不稳定，已回退。
8. 安全裕度硬航点与对应倾角同时固定：未采用，避免过度限制后端动力学优化。

七、当前可以认定的主要算法创新

1. 将负载位置 A* 扩展为负载位置与吊运构型联合搜索。
2. 构建包含路径长度、安全裕度、构型平滑和标称构型的环境-构型联合评价函数。
3. 通过位置和倾角联合插值实现相邻 A* 节点的连续可行性检查。
4. 在前端碰撞检查中统一考虑负载、缆绳和无人机物理尺寸。
5. 将前端构型路径传递给后端，并在 MINCO 中加入连续构型跟踪代价。
6. 在完整系统连续可行性约束下，对 A* 的负载位置与构型序列进行联合平滑，并将其作为安全走廊引导路径。
7. 根据环境复杂度和平滑后的前端构型生成考虑完整吊运系统包络的自适应凸多面体安全走廊。

其中前六项已经进入当前规划流程；第七项已完成生成和可视化，但尚未形成后端走廊约束闭环。
